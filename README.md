# Simple C# Application

This project is a simple C# console application called **Grocery Budget Checker**.

## What it does

- Asks the user for their name
- Accepts a total budget
- Accepts the cost of three grocery items: rice, bread, and milk
- Computes the total expenses
- Displays the remaining balance
- Shows whether the user is within budget, exactly on budget, or over budget

## How to run

Open the project in Visual Studio or use:

```powershell
dotnet run
```
